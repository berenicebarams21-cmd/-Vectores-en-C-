# Vectores en C++

# Descripción.


Este proyecto desarrolla un sistema básico de inventario utilizando vectores en C++. El programa almacena productos junto con sus precios, permite visualizar la información registrada, modificar el precio de un producto mediante su índice,calcular el precio promedio del inventario y consultar los datos correspondientes a una posición determinada dentro del vector. 

# Objetivo.

El objetivo principal es aplicar los conocimientos fundamentales sobre vectores, estructuras y ciclos en C++. Mediante este ejercicio se busca aprender a almacenar y manipular información de productos, acceder a elementos mediante índices, modificar datos existentes, recorrer colecciones y realizar operaciones matemáticas utilizando los valores almacenados dentro del inventario creado durante el desarrollo del programa.

# Funcionamiento.

El programa comienza creando un inventario con cuatro productos y sus respectivos precios. Luego muestra los datos almacenados y solicita un índice para modificar el precio correspondiente. Después calcula el promedio de todos los precios registrados. Finalmente, solicita una posición y muestra el producto y precio almacenados en dicha ubicación del vector utilizado.


# Lenguaje utilizado.

El proyecto fue desarrollado utilizando C++, un lenguaje de programación ampliamente utilizado para aprender fundamentos de programación y desarrollar aplicaciones eficientes. En esta tarea se emplearon estructuras struct, vectores mediante vector, cadenas de texto, variables numéricas, ciclos for, condiciones if, entrada mediante cin y salida mediante cout para gestionar el inventario.
